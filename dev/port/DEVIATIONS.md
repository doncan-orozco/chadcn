  | `toggle-group` | API: ToggleGroup as_child: React drops all root attributes and the caller's element (Slot clones the Context.Provider, toggle-group.tsx:32-47); the port keeps data-slot, role, dir, tabindex, style, data-* and the controller on the caller's element | DELIBERATE departure from strict 1:1, caused by an upstream shadcn quirk. WHAT REACT DOES: ToggleGroup renders <ToggleGroupContext.Provider> as the only child of <ToggleGroupPrimitive.Root> (toggle-group.tsx:32-47), so with asChild the Radix Slot clones the Provider (which ignores props) instead of the caller's element: data-slot, role, dir, tabindex, style, data-variant/size/spacing, classes and the roving-focus wiring are all dropped, the caller's element is never rendered, and only the items render. IMPACT: only callers that pass as_child to the ToggleGroup root; items, as_child on items and every other API map 1:1. HOW IT IS PINNED: scenario api__as-child-root was removed (it can never match the oracle: React renders 3 slots, Phlex 4) and test/components/v2/toggle_group_test.rb asserts the port's behavior.
